🚦 AI 交通安全工作坊：三步走實作手冊 🚀 開啟 AI 辨識系統 (index.html)

從零打造 AI 道路安全辨識網頁

不需安裝任何電腦軟體！只需透過瀏覽器，依序完成 **Roboflow 資料標註**、**Google Colab 雲端訓練** 與 **GitHub Pages 一鍵發布**。

📍 實作步驟目錄
1. Roboflow 標註與匯出 2. Google Colab 模型訓練 3. GitHub Pages 網頁發布
1

Roboflow：資料標註與資料集匯出

將收集好的 Google 街景圖片上傳至 Roboflow 平台進行標註，並匯出為 YOLO 訓練格式。

  1. 前往 Roboflow 官網 註冊並登入帳號。
  2. 點擊 Create New Project，選擇專案類型為 Object Detection，將標註類別命名為 crosswalk（斑馬線）。
  3. 點擊左側 Annotate 將照片拖曳上傳，點選照片開啟標註工具，使用 Bounding Box（畫框） 緊密框住照片中的斑馬線。
  4. 完成所有照片標註後，點擊左側選單的 Versions ➔ 點擊 Create New Version：
    • Preprocessing：設定 Resize 為 640x640（預設即有）。
    • Augmentation：可自由加入亮度（Brightness）或翻轉（Flip）等強化選項。
    • 點擊最下方 Create 產生版本。
  5. 版號產出後，點選右上角 Export Dataset ➔ 選擇格式為 YOLOv8 ➔ 選擇 show download code 並複製提示框中的 Python Code（包含你的 API Key）。
💡 提示：請將複製好的 Roboflow 下載程式碼妥善保存，待會將貼入 Step 2 的 Colab 中執行！
2

Google Colab：GPU 雲端模型訓練與 ONNX 轉換

利用 Google 提供的免費 GPU 算力訓練 YOLO 模型，並匯出為瀏覽器專用的 best.onnx 檔。

  1. 開啟 Google Colab，建立一份「新增筆記本」。
  2. 確認已開啟 GPU 加速：點選上方選單 執行階段 -> 變更執行階段類型 -> 選擇 T4 GPU。
  3. 將下方完整的 Python 腳本複製並貼入 Colab 的程式碼區塊中：
# 1. 安裝 Ultralytics (YOLO) 與 Roboflow 套件
!pip install ultralytics roboflow

# 2. 貼上你在 Step 1 複製的 Roboflow 下載程式碼
# (請將下方程式碼替換為你個人專屬的 Roboflow Code)
from roboflow import Roboflow
rf = Roboflow(api_key="YOUR_API_KEY")
project = rf.workspace("YOUR_WORKSPACE").project("YOUR_PROJECT")
dataset = project.version(1).download("yolov8")

# 3. 載入輕量化模型並開始訓練 (以 30 個 Epochs 為例)
from ultralytics import YOLO
model = YOLO('yolov8n.pt')
results = model.train(data=f"{dataset.location}/data.yaml", epochs=30, imgsz=640)

# 4. 將訓練完成的模型轉換為 Web 專用的 ONNX 格式
success = model.export(format='onnx')
print("✅ 模型匯出成功！請至左側資料夾下載 best.onnx 檔案。")
  1. 點擊左側工具列的 **「檔案 (資料夾圖示)」**，依序展開選單：
    runs ➔ detect ➔ train ➔ weights ➔ 找到 **`best.onnx`**。
  2. 在 **`best.onnx`** 上點擊右鍵選擇 **下載**，將模型檔儲存至個人電腦備用。
3

GitHub Pages：網頁一鍵部署與成果展示

將前端網頁 index.html 與剛下載的 best.onnx 檔案上傳至 GitHub，產出專屬的 AI 辨識網站！

  1. 登入 GitHub，點擊右上角 + -> New repository 建立新的儲存庫（如：crosswalk-ai-app）。
  2. 在專案頁面點擊 uploading an existing file，將以下檔案同時拖曳上傳：
    • index.html（包含前端與 JS ONNX Runtime 邏輯的網頁程式碼）
    • crosswalk.html（本教學手冊網頁）
    • best.onnx（剛從 Colab 下載的模型檔）
  3. 拖曳完成後，滑到最下方按下綠色的 Commit changes。
  4. 進入儲存庫頂部的 Settings -> 左側 Pages：
    • Source：選為 Deploy from a branch。
    • Branch：選擇 main 與 /(root)，按下 Save。
  5. 等待約 30 秒後重新整理頁面，頂部即會出現你的專屬公開網址（例：https://username.github.io/crosswalk-ai-app/）！
🎉 恭喜完成！打開公開網址，直接滑到最下方上傳街景圖片，即可體驗純地端 Edge AI 的斑馬線辨識與幾何安全度自動評估！
