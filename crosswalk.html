從零打造 AI 道路安全辨識網頁

不需安裝任何電腦軟體！使用工作坊提供的基礎街景資料包（80 張）搭配自選實拍圖，依序完成 Roboflow 資料擴充、Google Colab 一鍵訓練 與 GitHub Pages 網頁發布。

📍 實作步驟目錄
1. Roboflow 匯入與補標註 2. Google Colab 模型訓練 3. GitHub Pages 網頁發布
1

Roboflow：匯入基礎資料包與自選圖標註

為節省重複標註時間，我們已為大家準備好 80 張已標註完成的台灣路口街景資料包！你只需要匯入這批資料，再額外挑選 1～2 張 自己喜歡的街景照片親手完成標註即可。

  1. 準備素材：點擊前往 📥 下載基礎街景資料集 (Google Drive)
  2. 解壓縮工作坊提供的「80 張基礎資料集」，並另外從 Google 街景找 1～2 張新的路口照片。
  3. 前往 Roboflow 官網 註冊並登入帳號。
  4. 點擊 Create New Project，選擇專案類型為 Object Detection，建立標註類別（例如 crosswalk 斑馬線)
  5. 點擊 Upload Data 把剛剛準備的所有資料一起拖曳上傳並儲存（80 張會自動帶入標註框），接著點左側 Annotate，幫你額外找的那 1～2 張新照片畫框即可。
  6. 設定資料集分割比例 (Train / Valid / Test Split)：
    在匯出前確認資料切分為：70% 訓練集 (Train)、20% 驗證集 (Valid)、10% 測試集 (Test)，確保訓練與驗證集都有充足樣本。
  7. 點擊左側選單的 Versions ➔ 點擊 Create New Version 設定影像預處理與資料增強：
    • Preprocessing (預處理)：
      • Auto-Orient: Applied
      • Resize: Stretch to 640x640
    • Augmentations (資料增強 4 項)：
      • Flip: Horizontal（水平翻轉，模擬雙向車道視野）
      • Brightness: Between -15% and +15%（模擬晴天與陰天光照）
      • Exposure: Between -15% and +15%（模擬不同過曝與暗部環境）
      • Blur: Up to 2.5px（模擬行車動態模糊）
      • Outputs per training example: 3（每張訓練圖片產出 3 張擴增影像）
    • 點擊最下方 Create 產生版本。
  8. 版號產出後，點選右上角 Export Dataset ➔ 選擇格式為 YOLO26 ➔ 選擇 show download code 並複製提示框中的 Python Code（包含你的 API Key）。
💡 提示：匯入 80 張基礎資料包能確保訓練集與驗證集樣本充足、辨識率穩定；記得將複製好的 Roboflow 下載程式碼妥善保存，待會直接貼入 Step 2 的 Colab 中執行！
2

Google Colab：GPU 雲端模型訓練與 ONNX 自動下載

利用 Google 提供的免費 GPU 算力一鍵訓練 YOLO 模型，並自動轉換與下載瀏覽器專用的 best.onnx 檔。

  1. 開啟 Google Colab，建立一份「新增筆記本」。
  2. 確認已開啟 GPU 加速：點選上方選單 執行階段 -> 變更執行階段類型 -> 選擇 T4 GPU。
  3. 將下方完整的 Python 腳本複製並貼入 Colab 的程式碼區塊中（記得替換成你自己的 Roboflow 下載碼），點擊左側播放鍵執行：
# 1. 安裝 Ultralytics (YOLO) 與 Roboflow 套件
!pip install -q ultralytics roboflow

# 2. 貼上你在 Step 1 複製的 Roboflow 下載程式碼
# (請將下方 3 行替換為你個人專屬的 Roboflow Code)
from roboflow import Roboflow
rf = Roboflow(api_key="YOUR_API_KEY")
project = rf.workspace("YOUR_WORKSPACE").project("YOUR_PROJECT")
dataset = project.version(1).download("yolo26")

# 3. 載入輕量化模型並開始訓練 (以 30 個 Epochs 為例)
from ultralytics import YOLO
model = YOLO('yolo26n.pt')
results = model.train(data=f"{dataset.location}/data.yaml", epochs=30, imgsz=640)

# 4. 轉換為 Web 專用的 ONNX 格式並自動觸發瀏覽器下載
onnx_path = model.export(format='onnx', imgsz=640)
print(f"✅ 模型匯出成功！檔案位置：{onnx_path}")

from google.colab import files
files.download(onnx_path)
  1. 訓練與匯出完成後，瀏覽器會自動彈出下載視窗將 best.onnx 存到電腦的「下載」資料夾中。
  2. （備案）若瀏覽器阻擋自動下載，可點擊 Colab 左側工具列的 「檔案 (資料夾圖示)」 ➔ 依序展開 runs/detect/train/weights/ ➔ 在 best.onnx 上按右鍵選擇下載即可。
3

GitHub Pages：網頁一鍵部署與成果展示

將前端網頁與剛下載的 best.onnx 檔案上傳至 GitHub，產出專屬的 AI 辨識網站！

  1. 登入 GitHub，點擊右上角 + -> New repository 建立新的儲存庫（如：crosswalk-ai-app）。
  2. 生成網頁並上傳至 GitHub：
    1. 點擊前往 📄 複製 AI 網頁生成提示詞 (Google Docs) ，將內容完整貼給 ChatGPT / Gemini，讓 AI 幫你產生 index.html 程式碼。
    2. 取得程式碼後，透過以下任一方式放到 GitHub（務必確認 index.html 與 best.onnx 都在同一個儲存庫裡）：
      • 方式 A（直接貼上程式碼）：在 GitHub 點擊 Creating a new file ➔ 檔名輸入 index.html 並貼入程式碼 ➔ 按下 Commit changes 後，再點擊 Add file -> Upload files 上傳 best.onnx。
      • 方式 B（本機存檔後一起上傳）：將 AI 產生的程式碼存成電腦中的 index.html ➔ 在 GitHub 點擊 uploading an existing file，將 index.html 與 best.onnx 一起拖曳上傳並按下 Commit changes。
  3. 進入儲存庫頂部的 Settings -> 左側 Pages：
    • Source：選為 Deploy from a branch。
    • Branch：選擇 main 與 /(root)，按下 Save。
  4. 確認網頁部署進度 (Actions)：
    可點擊儲存庫頂部的 Actions 頁籤，查看 pages-build-deployment 是否出現綠色勾勾 ✅。完成後頂部即會出現專屬公開網址（例：https://username.github.io/crosswalk-ai-app/）！
🎉 恭喜完成！打開公開網址，上傳你剛剛自選的街景圖片，即可體驗純地端 Edge AI 的斑馬線辨識及安全度自動評估！
