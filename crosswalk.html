開始學習 黑客松任務

單元一：交通安全導論與 Google 街景危險因子採集 (80 mins)

📐 靜態危險度評估標準 (Rule-Based)

本系統結合駕駛視野與空間幾何比例，定義兩大關鍵道路安全緩衝門檻：

視線盲區門檻 (< 18%)
斑馬線底邊距離影像底部小於總高度 18% 時，代表過於貼近轉角或車頭死角，判定為高風險。
空間壓迫門檻 (> 25%)
斑馬線高度佔比超過影像總高度 25% 時，代表涵蓋近距離大面積視線盲區。
安全退縮標準
高於安全緩衝距離，符合道路退縮規範，駕駛擁有充足應變反應時間。

🌐 Google 街景資料採集步驟

模擬道路巡檢員，收集真實場景下的路口影像：

  • 1 開啟 Google Maps 並拖曳小黃人進入街景視角。
  • 2 搜尋學校周邊、無號誌路口或轉角危險斑馬線。
  • 3 調整視角至駕駛車頭角度（模擬行車視野）。
  • 4 截取 10-15 張 JPG 格式街景圖片備用。

單元二：Roboflow 影像標註與資料集建立 (75 mins)

1. 建立專案

選擇 Object Detection，並將 Detection Target 命名為 crosswalk。

2. 標註規範

框選斑馬線（Crosswalk）邊界，需拉框緊貼邊緣，不遺漏任何特徵。

3. 預處理與擴充

設定 Resize 640x640，加入 Brightness 與 Flip 強化模型泛化能力。

單元三：Google Colab 模型訓練與 ONNX 轉換 (60 mins)

請在 Google Colab（開啟 T4 GPU 算力）中貼上並執行以下 Python 訓練與匯出腳本：

# 1. 安裝 Ultralytics (YOLO) 與 Roboflow SDK
!pip install ultralytics roboflow

# 2. 下載 Roboflow 標註好的資料集
from roboflow import Roboflow
rf = Roboflow(api_key="YOUR_ROBOFLOW_API_KEY")
project = rf.workspace("aits-workshop").project("crosswalk-detection")
dataset = project.version(1).download("yolov8")

# 3. 啟動 YOLO 模型訓練
from ultralytics import YOLO
model = YOLO('yolov8n.pt') # 載入輕量化預訓練權重
results = model.train(data=f"{dataset.location}/data.yaml", epochs=30, imgsz=640)

# 4. 匯出跨平台 Web 專用 ONNX 格式
success = model.export(format='onnx')
print("✅ 模型轉換完成！請下載 runs/detect/train/weights/best.onnx")

單元四：GitHub Pages 一頁式 Web AI 部署 (60 mins)

🚀 GitHub Pages 發布流程

  1. 建立公開儲存庫（Repository），命名為 crosswalk-ai。
  2. 點選 Add file -> Upload files，上傳 index.html 與 best.onnx。
  3. 進入 Settings -> Pages，Source 選擇 Deploy from a branch。
  4. Branch 設定為 main / /(root)，按下 Save 完成免費發布。
